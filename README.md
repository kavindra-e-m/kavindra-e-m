### 🌟 Featured Projects

**🛒 Autonomous Follow-Me Shopping Cart** *(In Progress — 2026)*
Robotics capstone building a self-navigating cart using Raspberry Pi 5, Pi Camera, ultrasonic sensors, and ROS2 for real-time person-following and obstacle avoidance.

**💰 FinGuard AI — Intelligent Financial Assistant** *(2026)*
Full-stack ML platform for real-time financial behavior analytics. Random Forest for personality detection, Logistic Regression for stress prediction, Prophet/LSTM for expense forecasting, and Markowitz Mean-Variance optimization for portfolio allocation — with Monte Carlo retirement simulation and an interactive analytics dashboard.
`React` `Spring Boot` `FastAPI` `Python`

**🩺 Bio-Immune Kidney Monitor** *(2025)*
Wearable kidney-health monitor combining bioimpedance spectroscopy and microneedle ISF sensing for fluid-balance and biomarker tracking, with real-time signal processing and a mobile dashboard for early renal-dysfunction alerts.
`Embedded Systems` `Signal Processing` `Mobile Dashboard`

**🎥 PRISM — Prison Risk & Incident Surveillance Monitor** *(2025)*
AI-powered harassment detection system running real-time video analysis on a Raspberry Pi edge device, combining embedded hardware with deep learning for practical safety monitoring.
`Raspberry Pi` `Computer Vision` `Edge AI`
