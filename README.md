## 🌟 Featured Projects

### 🛒 ShopMate — Autonomous Follow-Me Shopping Cart
**2026 • Robotics / Edge AI • In Progress**

A smart shopping cart designed to autonomously follow its customer through a store while handling identification, navigation, safety and billing.

- **Raspberry Pi 5 (8 GB)** as main compute + **ESP32-S3** for BLE and real-time motor control
- USB camera + **ROS 2 / OpenCV / Python** for perception and control
- Customer-specific **BLE association**, person detection/tracking and customer recovery/search
- Obstacle detection and safety-aware motion control
- Barcode-based billing, phone-based billing interface and **UPI payment** workflow

`Raspberry Pi 5` `ESP32-S3` `ROS 2` `OpenCV` `Python` `BLE` `Computer Vision` `Edge AI`

### 🧠 VortieQ / Skilling — Adaptive AI Learning Platform
**2026 • Collaborative Project • HCL Hackathon Round 2**

An AI-powered platform that turns a learner's goal and existing skills into a personalized learning roadmap and continuously adapts it using real progress and feedback.

- Resume parsing and evidence-grounded skill assessment
- GitHub repository + commit analysis for real technical signals
- **Per-skill mastery modelling** with confidence-weighted evidence
- Semantic retrieval with **pgvector** and deterministic, explainable recommendation ranking
- Prerequisite-aware roadmap planning and target-timeline pacing
- Real-time **too easy / too hard / swap / completion** feedback adaptation
- Verified web + **YouTube Data API** resource retrieval and provenance
- Persistent AI coach, mock interviews, hackathon/internship discovery and progress analytics
- Production stack: **React + FastAPI + Supabase/PostgreSQL + AWS EC2 + Vercel + Docker + GitHub Actions**
- Security hardening, rate limiting, idempotency, RLS/IDOR verification and **300+ backend tests**

`React` `FastAPI` `Python` `Supabase` `PostgreSQL` `pgvector` `Groq` `AWS Bedrock` `Docker` `AWS EC2`

> Collaborative repository: [abi6374/vortieQ](https://github.com/abi6374/vortieQ) — contributed across frontend, backend, ML/recommendation, security and integrations.
